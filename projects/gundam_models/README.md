# Gundam models: Sazabi and Nu Gundam

Two mecha built from scratch in Blender, as display figures, from the product
photographs in `sources/raw/`: **Sazabi (MSN-04)** and **Nu Gundam (RX-93)**.

Everything here is geometry generated by the scripts in `code/` - boxes, tapered
boxes, extruded outlines and cylinders, assembled part by part. No mesh was
downloaded and no photograph was traced; the photographs were used the same way a
model kit's box art is used, as a visual reference for proportion, colour
separation and equipment.

**Copyright:** the designs are ©SOTSU·SUNRISE. These are fan-made approximations
for coursework, not licensed products, and the reference photographs are not
redistributed as assets - they sit in `sources/raw/` only as the visual reference
they are.

## What is in here

| Path | What it is |
| --- | --- |
| `model/sazabi.blend`, `model/sazabi.glb` | the editable scene and a glTF export (about 143 parts) |
| `model/nu_gundam.blend`, `model/nu_gundam.glb` | the same for Nu Gundam (about 130 parts) |
| `generated/renders/` | four views each (front, three-quarter, side, back), 1000×1300 |
| `code/mecha_kit.py` | shared kit: materials, armour primitives, vents, mirroring, studio, camera, export |
| `code/build_sazabi.py`, `code/build_nu_gundam.py` | the two builds, with the landmark table at the top of each file |
| `code/measure_refs.py` | measures the reference silhouettes (widths at heights) and writes `research/ref_measurements.json` |
| `code/image_to_3d.py`, `code/render_imported.py` | the image-to-3D attempt and the renderer used to inspect its output |
| `research/notes.md` | proportions, part inventory, what is approximated, and why the hand-built route was kept |
| `sources/raw/` | the six reference photographs (recovered from the repository object store after a mistaken delete) |

## Build and render

```powershell
$blender = "<path>\blender.exe"   # 4.5 LTS, portable, see the note below

& $blender -b --python code/build_sazabi.py    -- --render --views all --samples 96 --export
& $blender -b --python code/build_nu_gundam.py -- --render --views all --samples 96 --export
python code/measure_refs.py
```

Renders and exports are written to `week-07/artifacts/gundam/` and copied here by
`code/collect.ps1` (see below); the copies in `model/` and `generated/renders/`
are the ones to look at.

## Status, honestly

These are **stylised display figures**, not HG/RG reproductions. The silhouette,
the proportion, the colour separation and the equipment are there (mono-eye and
funnel rack on Sazabi; V-fin, asymmetric fin funnels and shield mark on Nu
Gundam), but the surface is made of about 130-140 beveled primitives per figure:
no panel lines, no decals, no articulation in the exported mesh. What they are
good for is a clean turntable or a comparison against the photographs, and as a
base that can be posed or detailed further.
