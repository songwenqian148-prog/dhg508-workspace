**Object:** Kalashnikov AK-47, **stage:** the Type 2 of 1951–1955, the milled
receiver built between the abandoned stamped Type 1 and the lightened Type 3.

This folder is the whole submission: sources, the two comparison images with
the written answers, the 3D model with renders and a turntable clip, and the
record of what each tool did.

## The short version of the result

**Step 2.** A words-only prompt produced a black, plastic-furniture rifle with an
invented optic: plausible as "an AK" and wrong for 1953. The same request plus
the two facts the sources establish (wooden furniture, no optic) produced a
wooden-stocked rifle - the right materials and the right decade - and still
invented a rail, an optic mount and a hand, and cropped the muzzle. Neither image
gets the milled receiver right; the sources changed what I asked for and what I
can *check*, not what the model is able to draw. The full answer, item by item,
is in [`research/comparison.md`](research/comparison.md).

**Step 3.** Two routes were run, because the brief allows either or both.

- **A, built by script in Blender 4.5** from the published dimensions (870 mm
  overall, 415 mm barrel, 4.3 kg) and from pixel measurements of the Commons Type
  2 photograph (stock 241 mm, receiver 291 mm, exposed barrel 338 mm). Parts are
  modelled one by one, so the Type 2-specific features are explicit. Renders at
  1800×1200 in `artifacts/renders/`, web-size copies in
  [`generated/renders/`](generated/renders).
- **B, Tencent Hunyuan3D 2 (image-to-3D)**, one photograph in, one mesh out:
  57 s, 57,480 triangles, untextured, correct silhouette, no parts at all
  (14,585 separate shells, not watertight). Both models are in
  [`model/`](model), and the two routes side by side are in
  [`generated/model_route_comparison.png`](generated/model_route_comparison.png).
  Numbers and failures: [`research/model_notes.md`](research/model_notes.md).

**Step 4.** The GLB is there to drop into a three.js viewer, and the turntable
clip is the demonstration piece: 60 frames, one full rotation, rendered in
Cycles.

## How this was built (so it can be rebuilt)

```powershell
# 1. Commons metadata for the 21 reference images -> sources/raw/provenance.json
python code/fetch_commons_metadata.py

# 2. the two text sources, as plain text with the URLs on line 1
python code/fetch_text_sources.py

# 3. the sources page, generated from the metadata above
python code/build_sources_doc.py

# 4. the two images (free tier: 1 image / 45 s, so this waits and retries)
powershell -NoProfile -ExecutionPolicy Bypass -File code/gen_final.ps1

# 5. the comparison sheet, the control figure, the manifest
python code/update_manifest.py
python code/make_comparison_sheet.py
python code/make_control_check.py

# 6. Blender: build, render stills, export, render turntable frames
$blender = "artifacts/tools/blender-4.5.14-windows-x64/blender.exe"
& $blender -b --python code/build_ak47_type2.py -- --hero --explode-still --export --samples 96 --gpu
& $blender -b --python code/build_ak47_type2.py -- --frames-png --samples 28 --frames 60

# 7. encode the frames
python code/encode_video.py

# 8. image-to-3D route (Hunyuan3D 2, anonymous Space call, ~1 min)
python code/hunyuan3d_try.py --shape-only --seed 1234 --steps 30 --octree 256
python code/prepare_hunyuan_asset.py artifacts/hunyuan/ak47_hunyuan3d_shape.glb ak47_hunyuan3d
& $blender -b --python code/render_glb.py -- --glb artifacts/hunyuan/ak47_hunyuan3d_shape.glb --prefix hunyuan
python code/make_model_comparison.py
```

Blender and its zip are git-ignored, so a fresh clone needs step 6's download:
<https://download.blender.org/release/Blender4.5/blender-4.5.14-windows-x64.zip>

## Status

Everything in the brief has a file behind it. Two honest limitations:

1. The image generator is weak on mechanical objects. The researched image shows
   the right *materials and era* and the wrong *assembly*. This is written up as
   the main difficulty rather than hidden by using the reference photograph as an
   image-to-image input.
2. The hand-built 3D model is a block-out, not a manufacturing model: barrels,
   springs and the bolt are single primitives, and the receiver has a shallow
   lightening pocket rather than the real machining. What it does preserve is the
   feature set that distinguishes the stages - milled one-piece receiver,
   one-piece wooden grip, wooden furniture, forward sling loop on the handguard,
   no bayonet lug, curved 30-round magazine.
